## Community Apps

- [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) - Open-source autonomous AI agent framework that chains LLM thoughts to achieve user-defined goals. Can be self-hosted and extended with plugins. MIT licensed. ([Read more](/details/autogpt.md)) `Open Source` `Self-Hosted` `AI-Powered` `API`
- [CrewAI](https://crewai.com/) - Open-source Python framework for orchestrating role-playing autonomous AI agents. Supports collaborative agent teams and tool use. Apache 2.0 licensed. ([Read more](/details/crewai.md)) `Open Source` `API` `AI-Powered` `Self-Hosted`
- [Gradio](https://gradio.app/) - Open-source Python library for building UIs for machine learning models and AI applications. Can be self-hosted or deployed to Hugging Face Spaces. MIT licensed. ([Read more](/details/gradio.md)) `Open Source` `Self-Hosted` `AI-Powered` `API`
- [mcp-use](https://github.com/mcp-use/mcp-use) - Open-source Python client library for interacting with Model Context Protocol servers. Enables applications to connect to MCP-compatible tools and data sources. MIT licensed. ([Read more](/details/mcp-use.md)) `Open Source` `Self-Hosted` `API` `AI-Powered`

## Dev & Testing Tools

- [Langfuse](https://langfuse.com/) - Open-source observability and analytics platform for LLM applications. Offers tracing, evaluations, and prompt management. Self-hosted or cloud-managed. ([Read more](/details/langfuse.md)) `Open Source` `Self-Hosted` `Freemium` `API` `AI-Powered`
- [LangSmith](https://smith.langchain.com/) - Developer platform for tracing, testing, and monitoring LLM applications built with LangChain. Provides debugging and evaluation tools. Paid plans available. ([Read more](/details/langsmith.md)) `Paid` `API` `AI-Powered` `Enterprise`
- [Promptfoo](https://promptfoo.dev/) - Open-source testing and evaluation framework for LLM applications. Supports red teaming, benchmarking, and continuous integration. Apache 2.0 licensed. ([Read more](/details/promptfoo.md)) `Open Source` `Self-Hosted` `API` `AI-Powered`

## Frameworks & SDKs

- [LangChain](https://langchain.com/) - Open-source framework for developing applications powered by language models. Includes tools for chaining models, agents, and data retrieval. MIT licensed. ([Read more](/details/langchain.md)) `Open Source` `API` `AI-Powered` `Self-Hosted`
- [LlamaIndex](https://www.llamaindex.ai/) - Open-source data framework for connecting large language models to external data. Supports indexing, retrieval, and agent workflows. MIT licensed. ([Read more](/details/llamaindex.md)) `Open Source` `API` `AI-Powered` `Self-Hosted`
- [Vercel AI SDK](https://sdk.vercel.ai/) - Open-source TypeScript SDK for building AI applications with streaming interfaces. Supports React, Next.js, Vue, Svelte, and Node.js. MIT licensed. ([Read more](/details/vercel-ai-sdk.md)) `Open Source` `API` `AI-Powered` `Free Plan`

## Partner Apps

- [Booking.com](https://www.booking.com/) - Official ChatGPT integration for searching hotels, flights, and rental cars. Users can ask travel questions and receive booking options directly in ChatGPT. Free to use; purchases are paid. ([Read more](/details/booking-com.md)) `AI-Powered` `Travel` `Free Plan` `API` `Free`
- [Canva](https://www.canva.com/) - ChatGPT plugin that lets users create designs, presentations, and social media graphics using natural language. Accessible via Canva's free and paid plans. Freemium. ([Read more](/details/canva.md)) `AI-Powered` `Design` `Freemium` `API`
- [Coursera](https://www.coursera.org/) - ChatGPT integration for discovering courses and specializations from universities and companies. Users can request recommendations and enroll through Coursera. Free to browse; courses may be paid. ([Read more](/details/coursera.md)) `AI-Powered` `Education` `Freemium` `API`
- [Expedia](https://www.expedia.com/) - ChatGPT travel plugin for booking hotels, flights, and activities. Users can plan trips and receive itinerary suggestions through conversational queries. Free to use; bookings are paid. ([Read more](/details/expedia.md)) `AI-Powered` `Travel` `Free Plan` `API` `Free`
- [Figma](https://www.figma.com/) - ChatGPT plugin for generating and editing Figma designs using text prompts. Supports design creation and iteration within the Figma editor. Free plan available; paid tiers for teams. ([Read more](/details/figma.md)) `AI-Powered` `Design` `Freemium` `API`
- [Instacart](https://www.instacart.com/) - ChatGPT integration for grocery shopping and meal planning. Users can ask for recipes and add ingredients to an Instacart cart for delivery. Free to use; groceries are paid. ([Read more](/details/instacart.md)) `AI-Powered` `Grocery` `Free Plan` `API` `Free`
- [Spotify](https://www.spotify.com/) - ChatGPT integration for discovering music and playlists based on natural language requests. Users can get recommendations and play tracks via Spotify. Free and Premium tiers available. ([Read more](/details/spotify.md)) `AI-Powered` `Music` `Freemium` `API`
- [Zillow](https://www.zillow.com/) - ChatGPT plugin for searching homes for sale or rent. Users can ask about listings, prices, and neighborhoods and receive Zillow results. Free to browse. ([Read more](/details/zillow.md)) `AI-Powered` `Real Estate` `Free Plan` `API` `Free`
